Ahoj z Example Company!

Máš za sebou několik let vývoje v Javě, Spring Boot používáš denně a chceš pracovat na systémech, které mají smysl? Pak bychom tě rádi poznali!

Kdo jsme

Jsme softwarová firma. Vyvíjíme systémy na klíč a našim klientům nabízíme vývojářské týmy. Používáme moderní technologie a dbáme na kvalitu, čitelnost a udržitelnost kódu.

Jak do toho zapadáš?

Zakázek přibývá, proto hledáme posilu. Na tomhle projektu se podílíme na vývoji nového nástroje pro klienta z oblasti logistiky.

Co bys měl mít, aby nám to klapalo?

Tvou hlavní náplní bude backendový vývoj v Java 17+ a Spring Boot a měl/a bys mít alespoň 3 roky komerčních zkušeností.
Znalost JPA a Hibernate pro efektivní práci s datovou vrstvou a mapování relací.
Zkušenosti s relational DB jako PostgreSQL nebo MySQL.
Praxi s návrhem a integrací REST a SOAP API.
Znalost Apache Kafka pro event-driven architekturu a asynchronní komunikaci mezi microservices.
Záleží ti na kvalitě kódu a máš praxi s automatizovaným testováním (JUnit, Mockito, případně Testcontainers)
Znalost Git pro správu verzí a orientaci v CI/CD pipelines pro automatizované sestavení a nasazení aplikace.
Schopnost spolupracovat v týmu, učit se od kolegů, případně sám kolegy přiučit něco nového.
Angličtinu a češtinu na komunikativní úrovni (denní stand-upy).

Co tě na projektu čeká?

Účast na projektu z oblasti logistiky.
Vývoj a správa microservices psaných v Java 17+ ve Spring Boot - od zadání, po implementaci, testy až po nasazení a provoz.
Práce v malém týmu vývojářů + PO, QA a TL.
Agilní prostředí - 2 týdenní sprinty včetně všech ceremonií.
Používání nástrojů jako Atlassian, Azure cloud, GraphQL, Sonar, Postgres, Kafka, Keycloak, Redis a další.
Přátelská atmosféra, kde se cení proaktivita.
